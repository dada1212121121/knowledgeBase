# 配置键清单（CONFIG_INDEX.md）

> 用途：`crates/kb-core/src/config/` 里 `Config` 的全部叶子键，一处列全。
> 设置页（`web-ui/src/utils/settingsFields.ts`）的 `path:` 只能写这里有的键，
> 由 `scripts/gen-config-index.mjs` 对表（`scripts/verify.sh` 会跑）。
>
> 重新生成：`node scripts/gen-config-index.mjs --write`
> 只对表：`node scripts/gen-config-index.mjs`
>
> 说明：
> - 这里只列**键**（点分路径，与 TOML 的段一一对应），不列默认值；
>   默认值与取值区间的对账在 `web-ui/src/utils/settingsFields.spec.ts`（它读 `impl Default`）。
> - 键是**大小写敏感的**，且必须是 `serde` 认的那个名字（有 `#[serde(rename)]` 的以重命名后的为准）。
> - 改键名要连三处一起改：`config/*.rs` 的字段、这里的清单（脚本重生成即可）、
>   前端 `settingsFields.ts` 的 `path`（漏了脚本会报）。
